🛠️ Troubleshooting
Chatbot is not responding
- Check the internet connection.
- Make sure the application is running.
- Verify required environment variables.
- Confirm that the configured AI service/API is available.
- Check the browser console for frontend errors.
- Check the terminal/server logs for backend errors.

API or AI response error
- Verify that the API key is correct.
- Check whether the API service is available.
- Confirm that the required environment variables are loaded.
- Restart the development server after changing environment variables.

Unexpected or incorrect answer
- Rephrase the question clearly.
- Provide additional context in the message.
- Verify important information through official sources.
